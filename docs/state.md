# Заметки по первой работе

19.09.2026. Первая лабораторная — два GET-запроса на Java и Spring Boot. Код находится в `LabApplication` и `LabController`, номер билета `1БКС24106` — в `application.yml`.

Проект собирается Maven Wrapper на JDK 21. Команда `.\mvnw.cmd verify` завершилась успешно: 4 теста прошли. При запуске JAR оба рабочих адреса вернули 200 с ожидаемым JSON, неизвестный адрес — 404.

Перед публикацией были просмотрены исходники и зависимости. Итог по версиям библиотек сохранён в [заметках](security-v1.md). Репозиторий опубликован по адресу `https://github.com/Rengen34/rbpo-lab1`. К концу первой работы основной коммит — `a26dba8`; к нему можно вернуться, если требуется собрать только первую версию.
