# Требования к первой лабораторной

По видимой части задания нужен небольшой проект на Java и Spring Boot, который собирается Maven и отвечает на два разных GET-запроса.

| Пункт | Что сделано |
| --- | --- |
| R1 | Java 17 и Spring Boot 3.5.16 |
| R2 | Сборка через `pom.xml` и Maven Wrapper |
| R3 | `GET /api/message` возвращает `{"message":"Проект работает"}`, `GET /api/numbers` — `{"numbers":[1,2,3]}` |
| R4 | `spring.application.name` равен номеру билета `1БКС24106` |
| R5 | Код опубликован в репозитории |
| R6 | Ссылка на репозиторий передаётся при сдаче в ЛМС |

За ответы отвечает `LabController`. Неизвестный адрес возвращает 404. Внешних данных и базы здесь нет.

Проверка: `.\mvnw.cmd verify` запускает четыре теста. Они проверяют оба ответа, неизвестный адрес и имя приложения. Для ручной проверки запустите `.\mvnw.cmd spring-boot:run` и откройте два адреса из таблицы на `localhost:8080`.
