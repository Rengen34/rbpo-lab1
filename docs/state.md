- До начала работы Git-репозиторий был пуст, без коммитов, Java-проекта и удалённого адреса.
- `docs/spec-v1.md` создан до исходного кода; содержит требования R1–R6 и сценарии.
- `pom.xml` задаёт Spring Boot 3.5.16, байткод Java 17, Web/Test/Jetty starter и исправленные версии Jackson/Log4j.
- `LabApplication` запускает сервер, `LabController` определяет два статических маршрута, `LabControllerTest` проверяет три HTTP-сценария.
- Официальный Maven Wrapper 3.3.4 закрепляет Maven 3.9.16 и контрольную сумму дистрибутива. Отдельно получен Maven 3.9.16 с официального Apache-источника и проверен SHA-512.
- Eclipse Temurin JDK 21.0.12.1+1 получен через официальный Adoptium API; SHA-256 архива совпал с метаданными. Пользовательские `JAVA_HOME` и `Path` указывают на этот JDK; системные настройки не менялись. Для отката удалить запись JDK из пользовательского `Path` и прежнее пустое `JAVA_HOME`, затем убрать каталог, на который указывал `JAVA_HOME`.
