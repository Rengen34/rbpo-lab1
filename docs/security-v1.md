# Проверка безопасности v1

Дата: 2026-09-19. Объём: локальный Java-проект версии 1.0.0, исходники, Maven-конфигурация, HTTP-маршруты и точные версии зависимостей. Проверка выполнена автором изменений; независимый тест на проникновение не проводился.

## Активы и границы

Приложение хранит только статический текст, три числа и номер студенческого билета в открытом конфигурационном файле. Секретов, пользователей, ролей, сессий, базы данных и внешних API нет. Сетевая граница — два публичных GET без параметров на локальном сервере Jetty. Неизвестный маршрут возвращает HTTP 404. Механизмы входа, разграничения прав, CSRF для изменяющих запросов, загрузки файлов, SQL-запросы и вебхуки к этой версии неприменимы; добавление таких функций потребует нового анализа.

## Проверки и результаты

| Контроль | Метод | Результат |
| --- | --- | --- |
| Компиляция и HTTP-контракт | `./mvnw.cmd -B -ntp verify`, JDK 21.0.12.1 | 4 теста прошли, jar собран |
| Пользовательский путь | запуск jar и три реальных GET на `localhost:8080` | два HTTP 200 с точным JSON, неизвестный путь — 404 |
| Конфигурация | тест `applicationNameMatchesTicket` и журнал запуска | `spring.application.name` равен `1БКС24106` |
| Зависимости | `maven-dependency-plugin:3.10.0:tree`, затем OSV `/v1/querybatch` по всем координатам и версиям | 97 компонентов, 0 известных записей на дату проверки |
| Секреты и лишние файлы | просмотр исходников и `git status` перед публикацией | секретов не обнаружено; `target/` исключён из Git |

Первичная проверка стандартных зависимостей выявила записи для Jackson 2.21.4, Log4j 2.24.3 и HTTP-сервера Tomcat 10.1.55, в том числе [ошибки контроля доступа Tomcat](https://github.com/advisories/GHSA-gcx9-497g-6cp6). Исправленные версии [Jackson 2.21.5](https://github.com/advisories/GHSA-5gvw-p9qm-jgwh) и [Log4j 2.25.5](https://github.com/advisories/GHSA-qv9r-c865-cp47) закреплены в `pom.xml`. HTTP-сервер Tomcat заменён на Jetty, поддерживаемый Spring Boot; исправленный Tomcat 10.1.58 не был доступен в Maven Central на дату проверки. Jetty starter по-прежнему приносит `tomcat-embed-el:10.1.55` для обработки выражений, но в этой версии приложения шаблоны и JSP не используются; компонент вошёл в повторную проверку OSV, которая дала ноль записей для точных версий. Первичные записи относятся к зависимостям; исходный HTTP API не использовал описанные в них пути аутентификации или десериализации входного JSON.

## Ограничения и сопровождение

Нулевой результат OSV означает только отсутствие известных записей в этой базе на указанную дату. Он не доказывает отсутствие уязвимостей; ручной обзор ограничен изменённым кодом и конфигурацией. Нагрузочное тестирование и проверка внешней сети не выполнялись. Полное соответствие OWASP ASVS не заявляется.

При обновлении версии Spring Boot или сервера заново выполните `./mvnw.cmd -B -ntp verify`, создайте актуальное дерево зависимостей командой `./mvnw.cmd -B -ntp org.apache.maven.plugins:maven-dependency-plugin:3.10.0:tree` и проверьте опубликованные рекомендации для новых версий. Проверяйте зависимости при каждом изменении `pom.xml` и перед публикацией проекта. При компрометации доступа к репозиторию отзовите токены и сеансы в настройках GitHub, проверьте историю изменений и заново опубликуйте проверенный коммит. Резервное копирование приложения сводится к хранению репозитория; данных для восстановления нет.
