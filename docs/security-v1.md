# Заметки по зависимостям первой работы

Проект первой лабораторной отвечает на два GET-запроса. Он не принимает данные в теле запроса и не хранит пользователей или пароли.

Для запуска выбран Jetty. В `pom.xml` также закреплены исправленные версии Jackson и Log4j. Библиотека `tomcat-embed-el` остаётся транзитивной зависимостью, но не служит HTTP-сервером; шаблоны и JSP здесь не используются.

19.09.2026 проект собрался на JDK 21: прошли 4 теста. При отдельном запуске оба адреса вернули 200 с ожидаемым JSON, неизвестный адрес — 404. Проверка 97 прямых и транзитивных зависимостей по точным версиям не нашла известных записей в OSV на эту дату. Это результат проверки по одной базе, а не гарантия отсутствия уязвимостей.

Если обновлять зависимости или сервер, нужно заново запустить `.\mvnw.cmd verify` и проверить новые версии.
